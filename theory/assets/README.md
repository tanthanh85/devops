## Visual conventions

- Blue represents delivery definitions and automation-platform components.
- Teal represents controlled execution or network components.
- Amber represents decisions, alerts, or approval points.
- Red represents a blocked path, failed gate, rollback, or remediation.
- Gray represents neutral supporting services, data stores, or lower-trust components.
